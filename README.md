# Object_Detection
Object detection using Raspberry Pi to control Robotic Arm


Models - YOLO/ mobilenet
Datasets - COCO, Pascal VOC, Open Images, Roboflow datasets and custom datasets

YOLO can detect objects such as people, cars, bicycles, motorcycles, animals, bottles, cups, phones, laptops, chairs and books
Training - pycharm/PC
Testing - using best.py - Raspberry Pi
